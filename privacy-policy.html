隐私政策

我们把隐私设计放在工具的核心：Processing Report 和可选 flat file 在浏览器中解析；工具页不加载广告、访问统计或第三方文件处理脚本。

Updated: 2026-06-06 - Independent seller utility, not affiliated with Amazon.

文件处理

上传到工具的 .txt、.csv、.tsv Processing Report 和可选 flat file 只在浏览器本地读取和解析，不会发送到我们的服务器，也不会发送给 Amazon、Google、Vercel 或其它第三方。

页面刷新或关闭后，当前解析结果会清空。请不要在公开 GitHub Issue、截图或反馈中提交真实店铺名、账号信息、买家信息、订单号、未公开 SKU 明细或完整商品目录文件。

访问统计

当前版本的工具页和内容页不加载 Vercel Web Analytics、Google Analytics 或其它访问统计脚本。若未来重新启用统计，应先在本政策和相关页面中明确说明统计范围，并保持文件内容不被采集。

广告与第三方服务

当前版本不在工具页加载 Google AdSense 或其它广告脚本。站点可能保留 ads.txt 或历史广告配置文件，但这些文件本身不会读取你的 Processing Report 或 flat file 内容。

外部链接会跳转到第三方网站；第三方网站的数据处理受其自身隐私政策约束。

本地解析的具体含义

当你选择 Processing Report 或 flat file 时，浏览器通过本地 JavaScript 读取文件内容，并在当前页面生成错误分组、变体分诊和可下载的 CSV/TSV 草稿。文件内容不会作为表单、API 请求、日志或分析事件发送出去。

如果你主动点击邮件草稿或 GitHub Issue 链接，只有你选择提交的摘要会进入对应第三方服务。联系页会把 public-safe 摘要和 private email brief 分开，尽量减少把 SKU、账号、订单或店铺细节发到公开位置的风险。

第三方链接

本站包含指向 GitHub、Google Search Console、Amazon Seller Central、Google AdSense 相关资料的外部链接。访问第三方网站时，请查看对应网站的隐私政策。
