Error 99010

Amazon 99010 错误：缺少必填字段

99010 通常表示当前分类模板、站点或商品类型要求的字段没有填写，或者字段组/列名与最新模板不一致。

Updated: 2026-06-07 - Independent seller utility, not affiliated with Amazon.

常见缺失字段

item_name、brand、product_type、recommended_browse_nodes、变体主题、分类必填属性。

修复步骤

  1. 在 Processing Report 中找到 attribute-name 或错误信息里的字段名。
  2. 回到最新版分类模板，查看 Data Definitions 页。
  3. 补齐所有 Required 字段，不要只补标题和品牌。
  4. 保存为制表符分隔文本后，先用少量 SKU 测试上传。

99010 不要只补一个字段

99010 表示当前模板上下文下仍有必填字段缺失。补上报告里点名的字段后，同一 SKU 可能继续暴露下一个 required field，因此更可靠的做法是回到 Data Definitions 页，一次性检查当前 product type、marketplace 和 variation theme 触发的整组必填字段。

复核前准备

  • 确认失败行是否为 parent 行、child 行或普通 SKU 行，因为必填字段集合不同。
  • 把报告中的 attribute-name 与原始 Flat File header 精确匹配，避免填错相似列。
  • 如果 repair draft 自动填了 variation theme，重新检查由该 theme 触发的 size、color、style、material 等字段。

程序化页面唯一诊断：99010 是动态必填字段缺失

99010 看起来最适合程序化生成，但风险也最高，因为必填字段不是固定清单。它会随 product_type、variation_theme、marketplace 和模板版本变化。页面必须提醒用户先定位 attribute-name，再根据当前分类模板确认该字段是否由 variation_theme 触发。不要把旧模板的固定字段清单当成全站规则；同一个 color-size theme 和 size-name theme 触发的必填列可能不同。

  • 先按 Processing Report 的 attribute-name 回到原始行。
  • 检查 variation_theme 是否触发 color、size、style 或 unit_count。
  • 若字段是 category-specific required，回到当前模板 Data Definitions 重新确认。
